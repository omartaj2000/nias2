# Crowdfunding Platform

A decentralised crowdfunding platform built on Ethereum. Campaign creators raise ETH directly via smart contract — no intermediaries, zero platform fees.

## Prerequisites

- Node.js 18+
- MetaMask browser extension (Sepolia testnet)
- MongoDB Atlas account
- Thirdweb account

## Installation

```bash
npm install

## Running the Application

```bash
npm run dev
```

The application will be available at `http://localhost:3000`.
